## Step 1 — OBS-20: `SessionCompiler` ABC + `split_blocks`

**File:** `src/agentvoca/observer/compile/base.py` (new)

Implement contracts §6's ABC, plus the shared blocking function.

```python
def split_blocks(bundle: SessionBundle) -> list[list[ObserverEvent]]:
    """Partition a session's events into blocks.

    A new block starts on a ``focus_change`` event, OR when more than
    ``_BLOCK_GAP_MS`` (5 minutes) elapse between consecutive events within
    the same app.

    ``pause_start`` / ``pause_end`` never open a block — they are recorded as
    ``gaps`` on the enclosing block, so a paused stretch does not fragment the
    narrative.

    Both compilers AND the JSON exporter call this one function, so markdown
    and JSON can never disagree about where blocks begin.
    """
```

Edge cases you must handle, because the fixture exercises all of them: an empty
session (return `[]`), a session whose first event is not a `focus_change`
(open an implicit block), and a session that is entirely `pause_*` events.

**Tests** — `tests/unit/test_compile_blocks.py`:
1. Fixture session → exactly the expected block count.
2. `focus_change` starts a new block.
3. A 6-minute same-app gap starts a new block; 4 minutes does not.
4. `pause_start`/`pause_end` do not split a block.
5. Empty session → `[]`.
6. First event not `focus_change` → one implicit block containing it.
7. `split_blocks` is pure — calling twice on the same bundle gives equal output.

## Step 2 — OBS-21: rules compiler (the zero-config default)

**File:** `src/agentvoca/observer/compile/rules.py` (new)

**This is the most important deliverable in your track.** D3 says Observer must
produce a genuinely useful artifact with no API key, exactly as
`cleanup.provider: rules` does today. If the rules output is not worth reading,
the zero-config promise is hollow.

Deterministic, no network, no LLM. Target output:

```markdown
# Session — 28 Jul 2026, 14:02–15:47

**Duration:** 1 h 45 m · **Apps:** Chrome, VS Code · **Captures:** 38 · **Spoken:** 24 lines

---

## 14:02 – 14:19 · Chrome
### Senior Backend Engineer — Acme | LinkedIn

**Said**
- 14:03 — "this role actually looks like a decent fit"
- 14:07 — "they want distributed systems experience, I have that from the payments work"

**Highlighted**
> 5+ years Python, distributed systems at scale, experience with Kafka
> or equivalent event streaming.

**On screen** *(3 captures)*
- 14:02 — Senior Backend Engineer · Acme · San Francisco, CA (Hybrid) · Posted 2 days ago
- 14:11 — About the role — You will own the ingestion pipeline that…

---

## 14:19 – 14:31 · VS Code
…

---

*Compiled by AgentVoca v0.4.0 · rules compiler · no LLM used*
```

Rules that make the output readable rather than a raw dump:

- **Timestamps** local time, `HH:MM`. Block headers get a range.
- **Deduplicate OCR** aggressively. Consecutive keyframes in one block usually
  share most of their text — show each keyframe's *first two non-empty lines*
  and drop lines already shown earlier in the same block. Raw OCR dumps are the
  single fastest way to make this output unreadable.
- **Truncate** each OCR excerpt at 200 chars with `…`.
- **Skip empty sections** entirely. A block with no speech has no **Said**
  heading — do not emit empty headings.
- **Selections** as blockquotes, truncated at 500 chars.
- **Gaps** rendered honestly and unmissably:
  `> ⚠️ 14:22–14:24 — capture paused (password manager in foreground)`
- **Escape** markdown-significant characters in OCR text and window titles.
  OCR output is untrusted text and will contain backticks, pipes, and
  underscores that will wreck the document.
- **Header stats** computed from the bundle, not guessed.

`degraded` is always `False`; `summary` is a one-line deterministic
"N spoken lines across M apps over H h M m" — enough to fill the JSON field
without pretending to be an LLM summary.

**Tests** — `tests/unit/test_compile_rules.py`, all against the OBS-9 fixture:
1. Compiles without network access (monkeypatch `httpx` to raise on any use).
2. Output contains a header for every block, in chronological order.
3. Every event kind in the fixture is represented somewhere in the output.
4. Empty sections are omitted — assert no `**Said**` heading in a speechless block.
5. OCR dedup: a repeated line appears once per block.
6. Markdown escaping: an OCR string of ``a|b `c` _d_`` does not break the table
   or emphasis rendering.
7. Gap rendering includes both the time range and the reason.
8. **Determinism:** compiling the same bundle twice gives byte-identical output.
9. Empty session compiles to a valid stub document, not a crash.
10. **Golden file:** commit `tests/fixtures/expected_session.md` and diff
    against it. This is what stops later refactors from silently degrading
    output quality.

## Step 3 — OBS-22: LLM compiler

**File:** `src/agentvoca/observer/compile/openai_compatible.py` (new)

RK7: never send a whole session in one request. Two-phase rolling
summarization:

1. **Per block:** send that block's utterances, selections, and deduped OCR
   (token-budgeted, ~2000 tokens in) and ask for a short narrative paragraph
   plus the key facts. Blocks are independent → run with `asyncio.gather`,
   order-preserving, per-block error isolation. This is the same pattern R10
   established for parallel vision extraction — read `_apply_vision` in
   `orchestrator.py` before writing it.
2. **Session:** send the per-block summaries only (never the raw events) and
   ask for the one-paragraph session summary.

Reuse `cleanup/openai_compatible.py` as the template for HTTP: persistent
`httpx.AsyncClient` with `keepalive_expiry=30.0` (R8) and the `shutdown()`
soft contract. Do not invent a third HTTP pattern in this codebase.

**Degradation is a hard requirement.** The ABC says `compile` must not raise.
If a block's LLM call fails, render **that block** with the rules compiler,
mark `degraded=True`, and continue. If the session-level call fails, use the
rules summary. A user who just recorded an hour of work always gets an
artifact. Test this explicitly.

The block markdown from the LLM is untrusted output: strip leading/trailing
code fences and any heading level above `###` so a chatty model cannot break
the document structure.

Prompts go in `observer/compile/prompts.py` as module-level constants, matching
`cleanup/prompts.py` and `vision/prompts.py`.

**Tests** — `tests/unit/test_compile_llm.py` (mock transport, no real API):
1. Block count in → same count of requests out; order preserved.
2. Parallel: with a 100 ms-per-call fake, 4 blocks complete in ≈100 ms, not 400.
3. One failing block → that block is rules-rendered, others are LLM-rendered,
   `degraded=True`.
4. Session-level failure → rules summary, `degraded=True`, blocks still LLM.
5. Total failure (every call fails) → output equals the pure rules compiler
   output and `degraded=True`. **`compile` still does not raise.**
6. Client reuse across calls (object identity) and `shutdown()` closes it.
7. Fence/heading stripping on a model response wrapped in ```` ```markdown ````.

## Step 5 — OBS-24: exporters

**Files:** `src/agentvoca/observer/export/markdown.py`, `json_sidecar.py`

```python
class Exporter(Protocol):
    name: str  # "markdown" | "json"
    def export(self, bundle: SessionBundle, compiled: CompiledSession, out_dir: Path) -> Path:
        """Write the artifact and return its path."""
```

- **Markdown:** write `compiled.markdown` to
  `<output_dir>/<session-uuid>/session.md`, UTF-8, `newline="\n"`.
- **JSON:** build contracts §5 **exactly** — `schema` string included — and
  write `session.json`, `indent=2`, `ensure_ascii=False`. Build the `blocks`
  array by calling `split_blocks` (never re-derive it), merging
  `compiled.blocks` summaries in by index.

Both create parent dirs, write to a `.tmp` file and `os.replace` into place so
a crash mid-write cannot leave a truncated artifact, and return the final path.

**Tests** — `tests/unit/test_export_markdown.py`, `test_export_json.py`:
1. Files land at the expected paths with correct content.
2. JSON validates against contracts §5: every required key present, correct
   types, `schema == "agentvoca.observer.session/1"`.
3. Block boundaries in the JSON match `split_blocks` exactly.
4. `blob_path` values are **relative**, never absolute (this is what makes the
   storage dir movable — assert it).
5. Non-ASCII (emoji, CJK) survives both formats.
6. Atomic write: no `.tmp` file remains after a successful export.
7. `formats: ["markdown"]` writes no JSON, and vice versa.

## Step 6 — OBS-25: privacy exclusions

**File:** `src/agentvoca/observer/privacy.py` (new)

```python
class ExclusionMatcher:
    """Decides whether the current foreground context must not be captured.

    Case-insensitive glob matching via fnmatch, mirroring how
    context/profiles.py already matches app names — read that file and follow
    its conventions rather than inventing new ones.
    """

    def is_excluded(self, app_name: str | None, window_title: str | None) -> tuple[bool, str | None]:
        """Returns (excluded, matched_pattern)."""
```

- `app_name` matched against `exclude_apps`, `window_title` against
  `exclude_title_patterns`.
- Case-insensitive on all platforms (Windows exe names vary in case).
- `None` app or title never matches — an unknown app is not automatically
  private. Document that choice in the docstring.
- Precompile the pattern lists in `__init__`; this is called at 2 Hz.
- Return the matched pattern so `pause_start` can record `meta["pattern"]`.

**Tests** — `tests/unit/test_privacy_exclusions.py`:
1. `"1Password.exe"` excluded; `"chrome.exe"` not.
2. Case-insensitivity: `"1PASSWORD.EXE"` excluded.
3. Title glob `"*Incognito*"` matches `"Foo - Incognito - Chrome"`.
4. `None`/`None` → not excluded.
5. Empty pattern lists → nothing excluded.
6. The matched pattern is returned, not just `True`.
7. Performance: 10 000 calls with 20 patterns complete in < 100 ms.

## Step 9 — OBS-28: attach, compile-on-stop, crash recovery

**File:** `src/agentvoca/main.py` — **only** your one marked line.

Replace:

```python
        # TRACK 3 REPLACES THIS LINE:
        observer_controller.attach_surface(None, None, None)
```

with construction of the compiler (`registry.get_compiler(cfg.observer.compile)`),
the exporter list from `cfg.observer.compile.formats`, and the
`ObserverIndicator`, then `attach_surface(...)`.

Wrap in `try/except Exception` that logs and degrades to
`attach_surface(None, None, None)` — a broken compiler must not stop the app,
and must not stop *recording* either. A session that cannot be compiled is
still a session worth keeping; the user can re-compile later.

**Crash recovery UX.** After the pipeline starts, if
`observer_controller.recover_sessions()` is non-empty, show a non-modal dialog:

> AgentVoca found 1 unfinished Observer session from 28 Jul, 14:02 (1 h 12 m).
> [Compile it] [Keep for later] [Delete]

- *Compile it* → mark `closed`, run compilation.
- *Keep for later* → leave `status='open'`; ask again next launch.
- *Delete* → `purge_session`.

Non-modal, after the pipeline is up, so it never blocks startup. Follow the
existing wizard's show/raise/activate pattern.

**Tests** — `tests/integration/test_observer_session.py` (the full-loop test,
using the OBS-9 fixture rather than real capture):
1. Fixture session → `stop_session()` → compilation runs → `session.md` and
   `session.json` exist and are non-empty.
2. `ObserverCompiledEvent` published with both paths.
3. Store status becomes `compiled`.
4. `formats: ["markdown"]` → no JSON written.
5. A compiler that raises → the session is still `closed`, no crash, error logged.
