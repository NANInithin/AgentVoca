How it works

Four steps from voice to cursor.

Each step can use a different provider, and you can swap any of them with one line in your config.

01

Listen

Hold a key to talk, press once to start and stop, or let it stop when you go quiet.

push_to_talk · toggle · auto_stop
02

Transcribe

Turn speech into text on your machine, or send it to any OpenAI-compatible endpoint.

faster-whisper · openai_compatible
03

Clean up

Remove filler, fix punctuation and apply your vocabulary. It never rewrites technical text.

rules · ollama · openai_compatible
04

Insert

Types straight into the focused app. Falls back to clipboard paste, with one-key undo.

keyboard · clipboard · undo
Features

Simple by default. Extra features when you want them.

Your basic setup keeps working as you add more. Every advanced feature is off until you turn it on.

Use cases

For when typing slows you down.

Use it anywhere you can type: your editor, terminal, chat, docs and AI tools.

Prompting AI tools

Explain the whole problem out loud instead of typing a short version. Your prompts come out longer and clearer, with exact file names.

"refactor the auth middleware in src slash server dot ts to use the new session helper"
Refactor the auth middleware in src/server.ts to use the new session helper.

Commits, issues and reviews

Talk through what changed and get tidy prose with the technical details intact, typed straight into Git, GitHub or your tracker.

"fix um the retry loop in fetch user new paragraph closes issue four twelve"
Fix the retry loop in fetchUser.

Closes #412.

Turning screens into text

Snip a spreadsheet, chart or error dialog while you talk. You get markdown, which costs far fewer tokens than an image when you paste it into another AI tool.

"make a table of the expenses as in the attached screenshot"
| Item | Amount |
| Hosting | €42.00 |

Recording a work session

Observer mode records what you say, what's on screen and what you highlight, then writes it up as a readable summary, with a structured data file alongside.

Session · 38 min · 14 keyframes · 6 selections
→ session-2026-11-10.md · session.json

Accessibility and less strain

Give your hands a break from RSI or fatigue. Push-to-talk, toggle and auto-stop let you choose how much you touch the keyboard.

Privacy-sensitive work

Use local speech and cleanup models for client code, health notes or anything under NDA. Your audio never leaves your machine.

Local-first & model-agnostic

Your models. Your machine.

The default setup runs fully offline. Point any step at Ollama, OpenAI or any compatible endpoint when you want to, and only that step sends data out.

  • Offline by default. Uses faster-whisper and rule-based cleanup, with no key or account needed.
  • Clear consent in Observer mode. An on-screen badge and a red tray icon show the whole time it's recording.
  • Exclusions and retention. Skips password managers and private windows, has a pause hotkey, and deletes sessions after 7 days.
  • No hidden uploads. Screenshots go out only when you snip one and turn on a cloud vision model.
# ~/.agentvoca/config.yaml
asr:
  provider: faster_whisper   # or openai_compatible
  model: small.en
cleanup:
  provider: ollama           # rules · openai_compatible
  model: qwen2.5:3b
app:
  mode: push_to_talk
streaming:
  enabled: true
observer:
  enabled: false
  compile: { provider: rules }
Install

Set up in under a minute.

A setup wizard opens the first time you run it. Choose "Use defaults" to start offline right away, or customize every setting.

01

Download

Get the latest Windows zip from Releases and extract it anywhere.

AgentVoca-vX.X.X-windows-x64.zip
02

Create the config folder

Run this once in PowerShell.

New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.agentvoca"
03

Run it

Start AgentVoca.exe, or run it from source on any platform with uv.

uv sync && uv run agentvoca

Stop typing. Start talking.
