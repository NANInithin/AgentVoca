# v0.4.0 — Observer Mode

**Status:** proposal — decisions locked with the project owner (2026-07-28)
**Target version:** v0.4.0
**Type:** new feature — new config block, new subsystem, new runtime deps
**Scope:** ambient audio, screen keyframes, OCR, selection capture, session storage, session compilation, tray/overlay surface

> Observer mode records a working session — what you said, what was on screen,
> what you highlighted, what app you were in — and compiles it at the end into
> a readable markdown document plus a machine-readable JSON sidecar.
>
> **Agent mode is explicitly NOT in this release.** It is v0.5.0. Observer's
> JSON sidecar is the contract Agent will consume; nothing in v0.4.0 executes
> a task, writes a file on the user's behalf, or calls a tool.
>
> Companion documents:
> - `v0.4.0-contracts.md` — **frozen interfaces. Read this first, all three agents.**
> - `v0.4.0-plan-agent1-foundation-storage.md` (Track 1: OBS-0 – OBS-9)
> - `v0.4.0-plan-agent2-capture-perception.md` (Track 2: OBS-10 – OBS-19)
> - `v0.4.0-plan-agent3-compilation-surface.md` (Track 3: OBS-20 – OBS-29)

## 1. Executive summary

| Capability | Mechanism | Offline? |
|---|---|---|
| Every spoken line during a session is recorded | Ambient tap on the existing mic stream + VAD utterance segmentation + the **already-configured** ASR provider | Yes (with `faster_whisper`) |
| Screen content is captured at meaningful moments | 4 trigger sources → rate-limited → active-window grab → perceptual-hash dedup | Yes |
| Screen content becomes text | RapidOCR (ONNX) local provider; optional cloud VLM escalation | Yes |
| Highlighted text is captured | Windows UI Automation `TextPattern`, read-only, **never touches the clipboard** | Yes |
| Dictation keeps working during a session | Mic fan-out + priority ASR arbiter (dictation preempts ambient) | Yes |
| The session becomes a usable document | `SessionCompiler` provider: `rules` (default, no API key) / `openai_compatible` / `none` | Yes (rules) |
| Output | Markdown + JSON sidecar; SQLite is the source of truth | Yes |

**Everything works with zero config and no API key**, exactly like today's
`cleanup.provider: rules` default. An LLM is a quality upgrade, never a
requirement. This is the single most important constraint in this document.

### Resource budget — a hard acceptance gate, not an aspiration

| Metric | Budget | Enforced by |
|---|---|---|
| Added idle CPU while a session is open | **< 5 %** on a 4-core laptop | 2 Hz foreground poll; token-bucket keyframe cap; phash dedup *before* OCR |
| Added RSS while a session is open | **< 400 MB** | Single shared ASR model (no second model); bounded queues; JPEG-on-write, never hold decoded frames |
| Sustained keyframes | **≤ 4 / min** | `observer.triggers.max_keyframes_per_min` token bucket |
| Audio callback p99 | **unchanged** (< 5 ms, the v0.3.6 budget) | Ambient tap is a `put_nowait` with drop-on-full — nothing else |
| Disk per hour, typical | **< 40 MB** | 1280 px JPEG q75, deduped, ~4/min |

If a track cannot hold its share of this budget, the correct response is to
reduce capture rate — **never** to exceed the budget.

## 2. Locked decisions

These were decided by the project owner. Do not revisit them; if you believe
one is wrong, raise it, do not silently change it.

| # | Decision | Rationale |
|---|---|---|
| D1 | **OCR = RapidOCR (ONNX) offline default**, optional `openai_compatible` VLM escalation | `onnxruntime` is already in `uv.lock` as a `silero-vad` transitive dep; models are ~15 MB; ~50–150 ms/frame on CPU. Reuses the v3 `VisionProvider` shape for the cloud path. |
| D2 | **Keep downscaled JPEG + text, auto-purge after `retention_days` (default 7)** | Allows re-processing with a better model and gives v0.5.0 Agent visual grounding, at ~50–150 KB/keyframe. |
| D3 | **Compiler is a provider: `rules` (default) / `openai_compatible` / `none`** | Mirrors `cleanup/` exactly. Preserves the zero-config, no-API-key property the product rests on. |
| D4 | **Windows-first; macOS graceful no-op** | UIA selection reading and window-rect capture are Win32. macOS gets the same abstraction with stubs that degrade cleanly (audio + app-name timeline still work). Parity targeted for v0.4.1. |
| D5 | **Selection via UI Automation, read-only, OCR-rect fallback** | Never injects keystrokes, never touches the clipboard. The repo already treats clipboard reads as privacy-gated. |
| D6 | **Capture scope = active window rect only** | Smallest images, least OCR, highest signal, and it never sweeps up other monitors or notification toasts. |
| D7 | **Explicit session start/stop (hotkey + tray)** | Unambiguous consent and clean artifact boundaries. Crash recovery offers an unclosed session for compilation at next launch. |
| D8 | **Dictation coexists with Observer**; dictated transcripts also land in the log tagged `utterance_dictated` | Requires mic fan-out + ASR arbitration. See §4.2 — this is the hardest part of the release. |
| D9 | **All four keyframe triggers ship**, each individually toggleable | Owner asked for "any change should be captured". See the note below. |
| D10 | **Observer reuses the configured dictation ASR model** (one instance) | No second model load, protects the 400 MB budget. Cost: arbitration complexity, and ambient lag during dictation. |
| D11 | **Privacy: exclusion list + persistent visible indicator + pause/resume hotkey + purge command** | |
| D12 | **No encryption at rest.** ACL-restricted directory only | Explicitly chosen over AES-GCM. See §7 for what this does and does not protect against. |
| D13 | **Markdown + JSON sidecar** | JSON is the v0.5.0 Agent contract; building it now avoids re-parsing prose later. |
| D14 | **3 execution tracks** | See §8. |
| D15 | **Laptop-safe budget** (§1) | |

> **Note on D9.** The owner's answer said "implement all 3" but four triggers
> were offered, alongside "any change should be captured". All four are
> implemented, including **speech-onset** — it is what grounds an utterance to
> a screen and is the single most valuable trigger for v0.5.0 Agent. It is
> behind `observer.triggers.speech_onset` and can be turned off in one line.
> **Flag this back to the owner at first review.**

> **Note on D12 vs D11.** The privacy question's fourth option bundled "purge
> command + on-disk encryption"; the follow-up question then chose "no
> encryption". The narrower, later answer wins: **purge ships, encryption does
> not.** `ObserverStore` keeps blob paths and text in separate columns
> specifically so encryption can be added in v0.4.1 without a schema
> migration.

## 3. Prerequisite bug: VAD is never instantiated (OBS-0)

**Verified:** `grep -rn "VAD(" src/` and `grep -rn "vad=" src/` both return
**zero matches**. `AudioCapture.__init__` accepts `vad: Optional[VAD] = None`
([capture.py:50](../../src/agentvoca/audio/capture.py#L50)) but
`_build_and_start_pipeline` in
[main.py:361-370](../../src/agentvoca/main.py#L361-L370) never passes one.

Consequences in shipped v0.3.6:

- `self._vad is None` → the `agentvoca-vad` worker thread from R2 is never started.
- `VADSpeechEvent` is never published.
- `app.mode: auto_stop` **silently never auto-stops**; only the
  `max_recording_duration_s` path terminates a recording.

Observer's ambient utterance segmentation is built on VAD, so this must be
fixed first. **OBS-0 is the first commit of Track 1.** It is a genuine
user-facing bug fix that stands on its own merit independent of Observer.

Note the design choice that follows from it: `AmbientListener` constructs its
**own** `VAD` instance rather than sharing `AudioCapture`'s. Silero is ~2 MB,
and sharing one stateful streaming VAD across the dictation and ambient
segmenters would require locking on the audio hot path. Two instances is
cheaper and simpler than one shared one.

**Do not reuse `capture/screenshot.py`.** It drives the *interactive* OS snip
UI (`ms-screenclip:`, `screencapture -i`) and blocks for up to 30 s waiting on
the user. Observer needs silent programmatic grabs. `observer/screen.py` is a
separate implementation using `PIL.ImageGrab.grab(bbox=...)`. Pillow is
already a dependency.

### 4.2 The mic fan-out (D8) — the hard part

The exact seam is [capture.py:255](../../src/agentvoca/audio/capture.py#L255):

```python
if not self._recording:
    return
```

Today the mic stream is open for the whole app lifetime but the callback
discards every block unless a dictation is active. Observer needs those blocks.

```
                    sounddevice callback thread
                              │
                   audio_bytes = indata.tobytes()
                              │
              ┌───────────────┴───────────────┐
              │                               │
     ambient sink.feed()              if not self._recording: return
     (put_nowait, drop-on-full)                │
              │                     ── existing v0.3.6 body, UNCHANGED ──
              ▼                                ▼
      AmbientListener thread            dictation buffer + chunker + VAD queue
      (own VAD, segments utterances)           │
              │                                ▼
              │                          Orchestrator._run_pipeline
              ▼                                │
        ASRArbiter.transcribe_ambient  ◄───────┤ ASRArbiter.transcribe_priority
              │        (waits while dictation holds the gate)
              ▼                                ▼
        utterance_ambient row            insert at cursor
                                          + utterance_dictated row
```

The ambient tap must be **strictly non-blocking** — a `queue.put_nowait` with
`except queue.Full: pass`, and nothing else. The v0.3.6 audio-callback p99
budget of 5 ms is not negotiable; R1–R3 exist precisely to protect it.

**ASR arbitration (D10).** One `ASRProvider` instance, two clients:

- Dictation calls `transcribe_priority()`. It sets an `asyncio.Event` to
  *unset* on entry and re-sets it on exit.
- Ambient runs a single worker coroutine draining a bounded `asyncio.Queue`.
  Before each job it does `await self._dictation_idle.wait()`.

So ambient work never delays dictation, and ambient transcription simply lags
(seconds) while a dictation is in flight. Ambient queue overflow drops the
**oldest** job and records a `gap` marker in the session, so the compiled
output can honestly say "audio dropped here" rather than silently losing it.

### 4.3 Keyframe pipeline

```
window/title change (2 Hz poll) ─┐
scroll settle (600 ms quiet)    ─┤
click / drag-select mouse-up    ─┼─► TriggerGate ─► CaptureQueue(8) ─► CaptureWorker
speech onset (from ambient VAD) ─┘        │                                  │
                                          │                           grab active window
                       min_interval_ms (4000) ────┐                   downscale to 1280px
                       token bucket (4/min) ──────┤                   dHash vs last 8
                       excluded app/title ────────┤                          │
                       session paused ────────────┘                   dup? drop, count
                                                                             │
                                                                    write JPEG q75
                                                                    INSERT keyframe row
                                                                             │
                                                                    OCRQueue(32) ─► OCRWorker
                                                                             │
                                                                    UPDATE events SET text=…
```

Every stage is bounded and drops rather than backs up. Dropping a keyframe is
always acceptable; missing the CPU budget is not.

`dHash` (difference hash) is implemented in-repo with Pillow + numpy — 8×9
grayscale resize, 64-bit hash, Hamming distance against the last 8 hashes,
threshold `observer.screen.dedup_phash_distance` (default 6). No new
dependency.

### 4.4 Data model

SQLite at `~/.agentvoca/observer/sessions.db`. Full DDL in
`v0.4.0-contracts.md` §3; summary:

- `sessions` — one row per session: `uuid`, `started_at_ms`, `ended_at_ms`,
  `status` (`open`/`closed`/`compiled`/`abandoned`), `app_version`,
  `schema_version`.
- `events` — the append-only timeline: `session_id`, `ts_ms`, `kind`,
  `app_name`, `window_title`, `text`, `blob_path`, `meta_json`.

`kind` ∈ `utterance_ambient`, `utterance_dictated`, `keyframe`, `selection`,
`focus_change`, `pause_start`, `pause_end`, `gap`.

**The DB is the source of truth. Markdown and JSON are renderings.** A crash
mid-session loses nothing beyond the in-flight queues, and any session can be
re-compiled later with a different provider.

## 7. Privacy, consent, and what D12 does not protect

**Ships in v0.4.0:**

1. **Off by default.** `observer.enabled: false`. Nothing records until the
   user turns it on *and* explicitly starts a session.
2. **Persistent visible indicator.** Tray icon state + a non-dismissable
   overlay badge for the entire session. The user can never forget it is on.
3. **Exclusion list.** Foreground app glob + window-title pattern. When
   excluded: no keyframe, no OCR, no selection. Ambient audio also suspends —
   an excluded app is excluded, not partially excluded. A `pause_start`/
   `pause_end` pair records the gap honestly.
4. **Pause/resume hotkey.** Instant suspend without ending the session.
5. **Purge.** Tray → *Observer* → *Delete all sessions…*, plus per-session
   delete. Removes DB rows, blobs, and exports.
6. **Retention.** Sessions older than `retention_days` (default 7) are purged
   at startup.
7. **Local by default.** With `ocr.provider: rapidocr` and
   `compile.provider: rules`, **nothing leaves the machine.** Choosing an
   `openai_compatible` OCR or compiler provider sends screen content and
   transcripts to that endpoint — the settings UI must say so plainly at the
   point of choice, matching how `docs/vision.md` handles it today.

**What D12 (no encryption) means, stated honestly for the docs:**

The session archive — transcripts, OCR text, window titles, and screenshot
JPEGs — sits in **plaintext** under `~/.agentvoca/observer/`, protected only
by a user-only Windows ACL. That defends against other user accounts on the
same machine. It does **not** defend against malware running as the user, a
stolen unencrypted drive, or a backup tool that sweeps the home directory.
Users who need that should enable BitLocker/FileVault, or keep
`retention_days` low. This must appear verbatim in `docs/observer.md` — do
not soften it.

**Legal.** Ambient microphone capture can record other people's voices. Some
jurisdictions require all-party consent. `docs/observer.md` carries a plain
note; the app does not attempt to give legal advice or geo-detect.

## 9. Test strategy

Observer is a background subsystem, so the release gate is heavier on
integration and resource tests than the v0.3.6 pass was.

**Determinism rule:** no Observer test may depend on wall-clock timing,
a real screen, a real microphone, or a real model. Every plan specifies the
fake to inject. A test that sleeps to wait for a worker is a broken test — use
the `drain()` / `flush()` barriers that T1 provides on every queue.

| Layer | What it proves | Owner |
|---|---|---|
| `tests/unit/test_observer_store.py` | Schema creation, migration from empty, event round-trip, retention purge deletes rows **and** blobs, crash-recovery finds `status='open'` | T1 |
| `tests/unit/test_observer_config.py` | Defaults; `observer.enabled: false` skips API-key validation; invalid combinations raise `ConfigError` | T1 |
| `tests/unit/test_ambient_tap.py` | Callback p99 < 5 ms with the tap installed; blocks reach the sink when `_recording` is False; drop-on-full never blocks | T2 |
| `tests/unit/test_asr_arbiter.py` | Dictation never waits on ambient; ambient resumes after; queue overflow drops oldest and records a `gap` | T2 |
| `tests/unit/test_trigger_gate.py` | `min_interval_ms` and the token bucket hold under a synthetic burst of 1000 triggers; excluded app emits nothing; paused emits nothing | T2 |
| `tests/unit/test_screen_dedup.py` | Identical frames dedup; a 1-word change does not; dHash is stable across JPEG round-trip | T2 |
| `tests/unit/test_ocr_rapidocr.py` | Provider contract against a stubbed engine; queue drop-on-full; failure isolates to one keyframe | T2 |
| `tests/unit/test_selection_uia.py` | UIA path with a mocked `comtypes` client; OCR-rect fallback; clipboard is **never** read or written (assert via a patched `pyperclip` that raises) | T2 |
| `tests/unit/test_compile_rules.py` | Zero-config compile of a fixture session produces valid markdown with every event kind represented | T3 |
| `tests/unit/test_compile_llm.py` | Rolling summarization chunks correctly; a failing block degrades to the rules rendering for that block only | T3 |
| `tests/unit/test_export_json.py` | Sidecar validates against the v0.5.0-facing schema in contracts §5 | T3 |
| `tests/unit/test_privacy_exclusions.py` | Glob and title matching; case-insensitivity on Windows | T3 |
| `tests/integration/test_observer_session.py` | Full fake-driven session: start → events → stop → compile → markdown + JSON on disk | T3 (after T2 merge) |
| `tests/integration/test_observer_dictation_coexist.py` | Dictation during a session inserts text normally **and** lands in the log as `utterance_dictated` | T2 |
| `tests/integration/test_observer_budget.py` | 10-minute simulated session: RSS delta < 400 MB, keyframe count ≤ 4/min, all queues bounded | T2 |

**Manual smoke before release** (Windows, real hardware — none of this can be
automated):

- 30-minute real session browsing a mix of apps; check CPU in Task Manager
  stays in budget and the machine does not get warm.
- Highlight text in Chrome, VS Code, Word, and a PDF viewer; confirm UIA
  capture or clean fallback, and confirm the clipboard is untouched
  (copy something first, verify it survives the whole session).
- Open a password manager mid-session; confirm zero keyframes and a
  `pause_start`/`pause_end` pair in the log.
- Dictate three times during a session; confirm insertion is unaffected and
  all three appear as `utterance_dictated`.
- Kill the process mid-session; relaunch; confirm the recovery prompt appears
  and compilation succeeds.
- Compile once with `rules` and once with `openai_compatible`; compare.

## 10. Risks

| ID | Risk | Mitigation |
|---|---|---|
| RK1 | Ambient tap regresses the audio callback and reintroduces the v0.3.6 robotic-audio symptom | Tap is a single `put_nowait` + `except Full: pass`. `test_ambient_tap.py` asserts the p99 < 5 ms budget with the tap installed. |
| RK2 | ASR contention makes dictation feel slower — the flagship feature regressing for a new one | Arbiter gives dictation absolute priority via an `asyncio.Event`; `test_asr_arbiter.py` asserts dictation never waits. Manual smoke measures perceived latency. |
| RK3 | RapidOCR accuracy is poor on dark themes / small UI fonts | Grab at native resolution, downscale **after** OCR is queued, never below 1280 px wide. If accuracy is unacceptable, the escape hatch already exists: `ocr.provider: openai_compatible`. |
| RK4 | UIA is slow or hangs on some apps (Electron, PDF viewers are known-bad) | UIA call runs on a worker thread with a **250 ms** hard timeout; on timeout, fall back to OCR-rect and log once per app. Never call UIA from the hook thread. |
| RK5 | `comtypes` COM apartment issues from a non-main thread | Initialize COM per worker thread (`CoInitializeEx(COINIT_APARTMENTTHREADED)`); one dedicated long-lived selection thread, never ad-hoc threads. |
| RK6 | Disk fills on a long session | `max_session_mb` (default 500) hard-stops keyframe capture, records a `gap`, and notifies via tray. Audio continues. |
| RK7 | Long session blows the LLM context at compile time | Rolling per-block summarization with a token budget per block, then a final composition pass. Never send a whole session in one request. |
| RK8 | `pynput` mouse listener conflicts with the existing keyboard listener | Both are pynput; run the mouse listener on its own thread and share nothing with `HotkeyManager`. Verified needed: `HotkeyManager` already owns a keyboard listener. |
| RK9 | Three-way merge conflict on `main.py` | T1 lands both `attach_*` stub call sites before T2/T3 start. Each later track replaces exactly one line. |
| RK10 | Scope creep toward Agent mode | Nothing in v0.4.0 may execute a task, call a tool, or write outside `observer.storage.dir` and `observer.compile.output_dir`. Any PR that does is out of scope by definition. |
