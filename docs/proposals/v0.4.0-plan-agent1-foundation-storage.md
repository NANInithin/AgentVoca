## Step 6 — OBS-5: `ObserverStore`

**File:** `src/agentvoca/observer/store.py` (new). The largest item in the track.

Implement contracts §3 exactly: the DDL, the public API, the on-disk layout.

**The threading contract is the whole design.** Get this right:

```python
class ObserverStore:
    def __init__(self, root: Path) -> None:
        self._root = root
        self._db_path = root / "sessions.db"
        self._blobs = root / "blobs"
        self._exports = root / "exports"
        self._queue: queue.Queue[_WriteJob | None] = queue.Queue()
        self._writer: threading.Thread | None = None
        self._conn: sqlite3.Connection | None = None   # writer thread ONLY
        self._started = False
```

- `start()` creates the directories (see OBS-6 for the ACL), opens the
  connection **on the writer thread**, applies the DDL, then starts accepting
  writes. Idempotent.
- Every write is a `_WriteJob` on the queue. `append()` enqueues and returns.
- `append_returning_id()` and `close_session()` enqueue a job carrying a
  `threading.Event` + a result slot, then wait on it. Use a timeout and raise
  `ObserverError` if it expires — never wait forever.
- `flush(timeout)` enqueues a barrier job and waits for it. **This is the
  primitive every test uses instead of sleeping.** Make it reliable.
- `stop()` enqueues the `None` sentinel, joins with a timeout, closes the
  connection **on the writer thread** before it exits. Idempotent, and safe to
  call when `start()` was never called.
- Reads (`load_bundle`, `list_sessions`, `find_open_sessions`, `session_bytes`)
  open a short-lived read-only connection (`file:…?mode=ro`, `uri=True`) on the
  calling thread and close it in a `finally`. Never reuse the writer's
  connection.

Other requirements:

- `ts_ms` monotonicity: keep a per-session `_last_ts_ms` on the writer thread
  and clamp with `max(ts_ms, last + 1)`. Wall-clock can go backwards (NTP,
  DST); the timeline must not.
- `meta_json`: `json.dumps` on write, `json.loads` on read. `set_event_text`
  **merges** into the existing dict — read, update, write — it does not replace.
- `purge_session` deletes the DB rows (the `ON DELETE CASCADE` handles events),
  then `shutil.rmtree` on `blobs/<uuid>` and `exports/<uuid>`, each guarded by
  `try/except OSError` with a logged warning. A missing directory is not an
  error.
- `purge_expired(retention_days)`: `retention_days == 0` disables purging and
  returns 0 immediately. Never purge a session with `status='open'`.
- `session_bytes` sums `os.path.getsize` over `blobs/<uuid>`; returns 0 if the
  directory is absent.

**Tests** — `tests/unit/test_observer_store.py` (use `tmp_path`, never the real

## Step 7 — OBS-6: storage directory + ACL (D12)

**File:** `src/agentvoca/observer/store.py` (extend), called from `start()`.

D12 chose no encryption, so the directory ACL is the **only** access control.
Implement it properly.

```python
def _harden_directory(path: Path) -> None:
    """Restrict ``path`` to the current user (Windows) or 0o700 (POSIX).

    Best-effort: a failure is logged and never raises. The user is told in
    docs/observer.md that the archive is stored in plaintext, so a failure
    here degrades an already-documented protection rather than breaking a
    promise the app made.
    """
```

- **Windows:** `icacls <path> /inheritance:r /grant:r "%USERNAME%":(OI)(CI)F`
  via `subprocess.run(..., check=False, capture_output=True)` with a short
  timeout. Use `os.environ.get("USERNAME")`; skip with a warning if unset.
  Never use `shell=True`.
- **POSIX:** `os.chmod(path, 0o700)`.
- Apply to the root only. `blobs/` and `exports/` inherit.
- Run once in `start()`, guarded so it does not re-run per session.

**Tests:** POSIX — assert mode `0o700` (skip on Windows). Windows — monkeypatch
`subprocess.run`, assert it is called with the expected argv and `shell` is not
set (skip on POSIX). Both platforms — a raising `subprocess.run` /
`os.chmod` does not propagate and `start()` still succeeds.

`session.py` holds the pure lifecycle state machine — no threads, no I/O beyond

```python
class SessionManager:
    """Owns the currently-open session and its paused state.

    Pure coordination over ObserverStore. No threads, no capture, no UI.
    Deliberately separated from ObserverController so the state transitions
    can be unit-tested without constructing any of the subsystems.
    """
    def open(self, app_version: str) -> ObserverSession: ...
    def close(self) -> ObserverSession | None: ...
    def pause(self, reason: str) -> bool:   # False if already paused
    def resume(self, reason: str) -> bool:  # False if not paused
    def record(self, kind: EventKind, **fields) -> None:
        """Append an event to the open session. No-op when closed or paused,
        EXCEPT for pause_start/pause_end/gap which are always recorded."""
    @property
    def current(self) -> ObserverSession | None: ...
    @property
    def is_paused(self) -> bool: ...
```
