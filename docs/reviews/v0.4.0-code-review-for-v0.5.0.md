# v0.4.0 production code review for v0.5.0

**Reviewed:** main at 88eff86, 2026-10-08. I read all 119 Python files under src/agentvoca (19,862 lines) and traced configuration, startup, runtime, UI, persistence, and shutdown. I inspected relevant tests and ran focused offscreen Qt and Python probes. This review does not certify live microphone, OS automation, or remote API behavior. The earlier baseline suite passed 853 tests with 4 skipped using a writable temporary USERPROFILE.

**Severity:** P0 blocks release because of privacy or data integrity; P1 breaks a core workflow or the proposed Agent dependency; P2 is narrower but actionable. File references below are source locations at the reviewed revision.

## Release order and checks

1. Fix R01–R02 and prove that excluded intervals produce zero sensitive rows, blobs, and remote OCR/ASR calls, including queued work.
2. Fix R03, R12–R14, R17–R18, R23 so a stopped session yields a complete sidecar or explicit incomplete status; Observer failure must leave dictation usable.
3. Fix R06–R11, R16, R21. Failed ASR and cancellation must never insert text; formatting and undo must be safe.
4. Fix R04–R05, R07, R15, R19–R20, R22, R24–R25. Settings saves must preserve all hidden fields and advertised hot fields must work.
5. Freeze the v0.5.0 sidecar and Agent contracts, implement Agent, then run a real Windows desktop smoke and a macOS smoke for advertised support.

The focused probes establish R04–R05, R09, and R22. Remaining source-confirmed findings need targeted regression tests at the indicated seam. The 853-test baseline was run before this review; passing tests do not resolve the findings.
