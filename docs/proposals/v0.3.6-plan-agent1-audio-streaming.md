## Step 1 — R1: delete the duplicate VAD inference (do this first)

**File:** `src/agentvoca/audio/capture.py`, `_audio_callback`.

Current code runs silero inference twice per 64 ms block:

```python
self._vad.process_chunk(audio_bytes, timestamp_ms)   # calls is_speech() internally
if not self._vad.is_speech(audio_bytes):             # second inference on same bytes
```

**Change:** call inference once and reuse the result. Because
`VAD.process_chunk` does not return the boolean, restructure the callback to:

```python
if self._vad is not None and self._vad.is_available:
    is_speech = self._vad.is_speech(audio_bytes)
    self._vad.emit_transition(is_speech, timestamp_ms)
    if not is_speech:
        silence_ms = int((time.time() - self._last_speech_time) * 1000)
        if silence_ms >= self._silence_timeout_ms:
            self.stop_recording()
    else:
        self._last_speech_time = time.time()
```

and in `src/agentvoca/audio/vad.py` refactor `process_chunk` into two parts so
no behavior is lost:

```python
def emit_transition(self, is_speech: bool, timestamp_ms: int) -> None:
    """Publish VADSpeechEvent when the speech state flips."""
    if self._last_speech_state is None or self._last_speech_state != is_speech:
        self._last_speech_state = is_speech
        self._event_bus.publish(VADSpeechEvent(is_speech=is_speech, timestamp_ms=timestamp_ms))

def process_chunk(self, audio_chunk: bytes, timestamp_ms: int) -> bool:
    """Run inference once and emit a transition event. Returns is_speech."""
    is_speech = self.is_speech(audio_chunk)
    self.emit_transition(is_speech, timestamp_ms)
    return is_speech
```

(Keeping `process_chunk` with a return value means the callback can simply do
`is_speech = self._vad.process_chunk(audio_bytes, timestamp_ms)` — prefer that
form; `emit_transition` exists so R2's worker can reuse it.)

**Test:** in `tests/unit/test_capture_vad_worker.py` (new file, shared with
R2): monkeypatch `VAD.is_speech` with a counting stub, feed N synthetic blocks
through `_audio_callback`, assert the counter equals N (not 2N). Check the
existing `tests/unit/test_capture.py` still passes.

## Step 3 — R4: kill the O(N²) copy in `_run_streaming_asr`

**File:** `src/agentvoca/asr/faster_whisper.py`, `stream_transcribe`, the
`async for chunk in audio_stream:` loop (~lines 399–439).

**Problem (verified):** every 500 ms iteration executes
`np.frombuffer(bytes(full_buffer), dtype=np.float32)` — a full copy of the
entire recording — then windows it, then copies *again* into `snapshot`.
Additionally the window is built on **every** chunk even when the previous
partial is still running and the array is thrown away.

**Change** — restructure the loop body so the window is materialized only when
a new partial is actually submitted, using a memoryview slice with exactly one
copy:

```python
async for chunk in audio_stream:
    full_buffer.extend(chunk)

    min_partial_bytes = int(0.5 * sample_rate) * 4  # 500 ms minimum
    if len(full_buffer) < min_partial_bytes:
        continue

    # Yield any completed partial result (non-blocking check)
    if _partial_fut is not None and _partial_fut.done():
        ... # unchanged
        _partial_fut = None

    # Start a new partial only when no other is running.
    if _partial_fut is None:
        snapshot = self._window_snapshot(full_buffer, window_s, sample_rate)
        lang = context.language_hint if context else self._config.language_hint
        _partial_fut = loop.run_in_executor(
            None,
            lambda a=snapshot, lg=lang: streaming_model.transcribe(
                a, language=lg, beam_size=1, vad_filter=False
            ),
        )
```

with a helper (method or module function):

```python
@staticmethod
def _window_snapshot(buffer: bytearray, window_s: int, sample_rate: int) -> np.ndarray:
    """Copy the last ``window_s`` seconds out of ``buffer`` with one allocation.

    A memoryview slice avoids copying the whole buffer. The temporary
    frombuffer view MUST be dropped before this function returns: while it is
    alive it holds a buffer export, and the caller's next
    ``buffer.extend(...)`` would raise ``BufferError`` (bytearray cannot
    resize while exported).
    """
    mv = memoryview(buffer)
    if window_s > 0:
        window_bytes = window_s * sample_rate * 4  # float32
        if len(mv) > window_bytes:
            mv = mv[-window_bytes:]
    view = np.frombuffer(mv, dtype=np.float32)
    snapshot = view.copy()
    del view
    mv.release()
    return snapshot
```

Notes:
- The old `snapshot = audio_array.copy()` line is **replaced** by this — do
  not end up with two copies.
- Leave the final accurate pass (`bytes(full_buffer)` after the stream ends)
  as-is: it runs once, and after the stream ends nothing resizes the buffer.
  Changing it buys nothing.
- Do not bind the intermediate `np.frombuffer` result anywhere that outlives
  the helper. This is the entire safety argument.

**Tests:** new `tests/unit/test_streaming_no_quadratic_copy.py`:
1. **Churn bound:** drive `stream_transcribe` with a fake audio stream (async
   generator yielding ~500 ms float32 chunks, total ≥ 60 s of audio) and a
   monkeypatched streaming model whose `transcribe` returns instantly. Wrap
   the run in `tracemalloc`; assert peak allocation stays under
   `len(total_audio) * 3` (generous — the old code would blow past
   `len * O(chunks)`).
2. **BufferError regression:** call `_window_snapshot`, then immediately
   `buffer.extend(b"\x00" * 4096)` — must not raise.
3. **Equivalence:** for a known buffer, assert `_window_snapshot` returns
   byte-identical data to the old `np.frombuffer(bytes(buf))[-window:]` path.

## Step 4 — R5: compact the chunker buffer

**File:** `src/agentvoca/audio/chunker.py`, `_get_delta` (~lines 132–137).

**Problem:** `self._buffer` only ever grows; it holds a duplicate of the whole
recording for the entire dictation.

**Change:**

```python
def _get_delta(self) -> bytes:
    """Return new audio since the last emission and compact the buffer.

    ``end`` is snapshotted before the delete: ``add_audio`` may append from
    the audio thread between the two statements, and deleting only ``[:end]``
    guarantees those new bytes survive. Both the slice-read and the delete are
    single GIL-held bytearray operations, so no torn state is possible.
    """
    end = len(self._buffer)
    delta = bytes(self._buffer[self._last_emit_pos:end])
    del self._buffer[:end]
    self._last_emit_pos = 0
    return delta
```

`self._last_emit_pos` becomes always 0 after compaction but keep the attribute
and the `reset()` semantics (other code and tests reference it). Verify
`reset()` and `start()` still leave a consistent state (`_buffer` empty,
`_last_emit_pos = 0` — they already do).

**Tests:** extend `tests/unit/test_chunker.py`:
- Feed 10 × 100 KB, emit deltas between feeds; assert every delta is
  byte-identical to the pre-change behavior (concatenation of deltas ==
  concatenation of inputs) and `len(chunker._buffer)` never exceeds the bytes
  added since the previous emission.
- Flush path: `stop(flush=True)` still emits the tail delta exactly once.

## Step 5 — R3: get `stop_recording()`'s heavy work off the audio callback

**File:** `src/agentvoca/audio/capture.py`.

**Problem:** on auto-stop (silence timeout or max duration), `stop_recording()`
executes inside `_audio_callback` and performs `b"".join(self._audio_buffer)`
— a multi-MB copy on the real-time audio thread — plus event publication.

**Change:** split `stop_recording` into a cheap trigger and a finalizer:

```python
def stop_recording(self) -> None:
    """Stop capturing audio and emit ``RecordingStoppedEvent``.

    Cheap and callback-safe: flips flags and schedules the buffer join +
    event publish on the asyncio loop thread. Falls back to inline
    finalization when no loop was provided (tests, headless use).
    """
    if not self._recording:
        return
    self._recording = False
    self._stop_requested = True

    if self._chunker is not None and self._loop is not None:
        asyncio.run_coroutine_threadsafe(self._chunker.stop(flush=True), self._loop)

    duration_ms = int((time.time() - self._record_start_time) * 1000)
    if self._loop is not None:
        self._loop.call_soon_threadsafe(self._finalize_stop, duration_ms)
    else:
        self._finalize_stop(duration_ms)

def _finalize_stop(self, duration_ms: int) -> None:
    """Join the buffer and publish RecordingStoppedEvent (loop thread)."""
    audio_bytes = b"".join(self._audio_buffer) if self._audio_buffer else b""
    self._event_bus.publish(
        RecordingStoppedEvent(
            audio_bytes=audio_bytes,
            duration_ms=duration_ms,
            sample_rate=self._sample_rate,
        )
    )
    logger.debug("Recording stopped (%d ms, %d bytes)", duration_ms, len(audio_bytes))
```

Correctness arguments you must preserve:
- After `self._recording = False`, `_audio_callback` returns before touching
  `_audio_buffer`, so the join on the loop thread sees a stable list.
  (`self._recording = False` must be set **before** scheduling the finalizer —
  it already is in this ordering.)
- Ordering vs. the chunker flush: both the flush coroutine and the finalizer
  are enqueued on the same loop from the same thread, flush first, so the
  `AudioChunkEvent(is_flush=True)` is processed before `RecordingStoppedEvent`
  — same ordering as today.
- `cancel_recording()` stays synchronous (it only clears state; no join).

**Tests:** new `tests/unit/test_capture_stop_offthread.py`:
- With a stub loop (a real `AsyncLoopThread` from `core/async_loop.py`),
  record N appended buffers, call `stop_recording()` from a non-loop thread,
  and assert the `RecordingStoppedEvent` payload equals `b"".join(buffers)`
  and that its publishing thread is the loop thread (capture
  `threading.current_thread().name` inside a subscriber).
- With `loop=None`, assert inline behavior is unchanged (existing
  `test_capture.py` expectations).
- Double-stop: second `stop_recording()` is a no-op (guard added above).

## Step 6 — R2: move VAD inference off the audio callback

**File:** `src/agentvoca/audio/capture.py` (+ `vad.py` from Step 1).

**Design (this replaces the rev-1 sketch, which was rejected because
`asyncio.Queue.put_nowait` is not thread-safe from the audio thread and its
consumer blocked the asyncio loop with ONNX inference):**

- A **`queue.Queue(maxsize=64)`** (stdlib, thread-safe) carries
  `(audio_bytes, timestamp_ms)` tuples from the callback.
- A **dedicated daemon worker thread** (`agentvoca-vad`) owns all silero
  inference. Not the asyncio loop: inference (5–20 ms+) would otherwise block
  streaming-ASR scheduling and event dispatch.
- The callback reads/writes only two attributes: puts to the queue
  (drop-on-full) and reads the cached `self._last_vad_speech` bool.
  GIL-atomic; no locks needed.
- Timing math: callbacks arrive every ~64 ms (`frames_per_buffer=1024` @
  16 kHz). A 64-deep queue bounds staleness at ~4 s in the worst case, but the
  worker drains far faster than real-time; the staleness test below enforces
  the practical bound.

Implementation:

```python
# __init__ additions
self._vad_queue: "queue.Queue[tuple[bytes, int] | None]" = queue.Queue(maxsize=64)
self._last_vad_speech: bool = True   # optimistic: never auto-stop before first result
self._vad_thread: Optional[threading.Thread] = None

# start(): after the stream opens, if self._vad is not None:
self._vad_thread = threading.Thread(target=self._vad_worker, name="agentvoca-vad", daemon=True)
self._vad_thread.start()

# stop(): after closing the stream:
if self._vad_thread is not None:
    self._vad_queue.put(None)          # sentinel; blocks at most briefly
    self._vad_thread.join(timeout=2.0)
    self._vad_thread = None

# start_recording(): reset per-recording VAD state
self._last_vad_speech = True
while not self._vad_queue.empty():     # drop stale blocks from a prior recording
    try:
        self._vad_queue.get_nowait()
    except queue.Empty:
        break

def _vad_worker(self) -> None:
    """Dedicated thread: silero inference + speech-state cache updates."""
    while True:
        item = self._vad_queue.get()
        if item is None:
            return
        audio_bytes, timestamp_ms = item
        if self._vad is None or not self._vad.is_available:
            continue
        try:
            self._last_vad_speech = self._vad.process_chunk(audio_bytes, timestamp_ms)
        except Exception:
            logger.debug("VAD worker inference failed", exc_info=True)
            self._last_vad_speech = True   # fail open, same as VAD.is_speech
```

Callback replacement for the Step-1 block:

```python
if self._vad is not None and self._vad.is_available:
    try:
        self._vad_queue.put_nowait((audio_bytes, timestamp_ms))
    except queue.Full:
        pass  # worker is behind; skipping a block is harmless
    if self._last_vad_speech:
        self._last_speech_time = time.time()
    else:
        silence_ms = int((time.time() - self._last_speech_time) * 1000)
        if silence_ms >= self._silence_timeout_ms:
            self.stop_recording()
```

Notes:
- `VAD.process_chunk` (with the Step-1 return value) already publishes
  `VADSpeechEvent` on transitions — from the worker thread now. That's the
  same cross-thread publish pattern the callback used before;
  `EventBus.publish` handles it (async handlers go through
  `run_coroutine_threadsafe`). No event changes.
- `stop_recording()` is safe to call from the callback after Step 5 (cheap).
- **Optional sub-step (do only if tests stay green):** switch
  `VAD.is_speech` from `silero_vad.get_speech_timestamps` (a batch
  segmentation utility, heavy per 64 ms block) to the streaming API — feed
  512-sample frames to the model directly and threshold the probability.
  Keep the current implementation as fallback if the silero version in
  `uv.lock` lacks it. This is an optimization *inside* the worker; the
  architecture above doesn't depend on it.

**Tests:** `tests/unit/test_capture_vad_worker.py` (extends Step 1's file):
1. **Callback latency:** monkeypatch `VAD.is_speech` with a stub that sleeps
   10 ms (simulating inference). Feed a synthetic 30 s stream (469 blocks of
   1024 float32 frames) through `_audio_callback` directly, timing each call;
   assert p99 < 5 ms (the callback no longer waits on inference).
2. **Auto-stop still works:** stub VAD returns speech for 1 s of blocks then
   silence; with `silence_timeout_ms=900`, assert `stop_recording` fires
   within `900 ms + 3 blocks` of simulated time (drive `time.time` with a
   fake clock or use generous real-time bounds).
3. **Stale-queue hygiene:** fill the queue, call `start_recording()`, assert
   the queue is empty and `_last_vad_speech` is True.
4. **Shutdown:** `start()` + `stop()` joins the worker within 2 s.

## Step 7 — R6: make Cancel actually cancel

**Files:** `src/agentvoca/core/orchestrator.py`,
`src/agentvoca/audio/capture.py`, `src/agentvoca/main.py`.

**Verified reality (why the rev-1 A5 is wrong, don't re-introduce it):**
- `cancel_recording()` never publishes `RecordingStoppedEvent`, so no pipeline
  starts and nothing hangs on `_stream_final_event`.
- `prepare_for_recording()` (wired via `loop_thread.call_soon` in `main.py`'s
  toggle branch) already resets streaming state before each new recording.
- The actual bugs: (a) after cancel, the orphaned `_stream_task` keeps
  transcribing stale audio and publishing `PartialTranscriptEvent`s until the
  next recording; (b) cancel pressed *after* stop, while `_run_pipeline` is in
  flight, does nothing — the text still gets inserted.

**Change 7a — track the pipeline task.** In `_on_recording_stopped`, replace
the direct `await self._run_pipeline()` with a tracked task:

```python
self._pipeline_task = asyncio.create_task(self._run_pipeline())
try:
    await self._pipeline_task
except asyncio.CancelledError:
    logger.info("Pipeline cancelled by user")
finally:
    self._pipeline_task = None
```

Add `self._pipeline_task: Optional[asyncio.Task[None]] = None` to `__init__`.
`_run_pipeline`'s existing `finally: self._reset_streaming_state()` still runs
on cancellation — that's load-bearing, keep it.

**Change 7b — `Orchestrator.cancel()`.** New synchronous method (sync so it
can be scheduled with `call_soon` from the Qt thread, mirroring
`prepare_for_recording`):

```python
def cancel(self) -> None:
    """Abort the current dictation: stream task, in-flight pipeline, state.

    Runs on the loop thread (schedule via ``loop_thread.call_soon``). Safe to
    call in any state; idempotent.
    """
    if self._pipeline_task is not None and not self._pipeline_task.done():
        self._pipeline_task.cancel()
    self._reset_streaming_state()   # cancels _stream_task, drains queue, clears events
    self._current_audio_bytes = None
    self._current_transcript = None
    if self._state_machine.state != "idle":
        self._state_machine.reset("idle")
```

Do **not** publish `StateChangedEvent` here — `main.py`'s cancel branch
already publishes one; a second would flicker the overlay.

Cancellation-point note: `_run_pipeline` awaits provider calls; cancelling the
task raises `CancelledError` at the current await, so a cancel that lands
before `_run_insertion` starts prevents insertion entirely. A cancel landing
*during* `typewrite` cannot un-type — that is accepted and documented in the
parent doc.

**Change 7c — wire the hotkey.** In `main.py`, `on_hotkey`, cancel branch:

```python
elif action == "cancel":
    logger.debug("Cancelling recording")
    audio.cancel_recording()
    loop_thread.call_soon(orchestrator.cancel)
    event_bus.publish(StateChangedEvent(previous="recording", current="idle"))
```

**Change 7d — guard `cancel_recording()`.** In `capture.py`, top of
`cancel_recording`: keep it callable when not recording (the buffer clear is
harmless and cancel-after-stop relies on the orchestrator side), but skip the
chunker stop when there is nothing to stop:

```python
def cancel_recording(self) -> None:
    """Stop recording (if active) and discard the audio buffer."""
    was_recording = self._recording
    self._recording = False
    self._stop_requested = True
    self._audio_buffer = []
    if was_recording and self._chunker is not None and self._loop is not None:
        asyncio.run_coroutine_threadsafe(self._chunker.stop(flush=False), self._loop)
    logger.debug("Recording cancelled (was_recording=%s)", was_recording)
```

**Tests:** new `tests/integration/test_cancel_semantics.py` (model it on
`tests/integration/test_streaming_pipeline.py`'s fixtures):
1. **Ghost-partial kill:** start a streaming dictation with a slow fake ASR
   provider that yields partials forever; cancel mid-stream; assert no
   `PartialTranscriptEvent` is published after `cancel()` returns (subscribe
   and timestamp), and `orchestrator._stream_task` is None/done.
2. **Cancel after stop:** fake ASR final segment + a cleanup provider with a
   500 ms delay; publish `RecordingStoppedEvent`, then call `cancel()` during
   the cleanup await; assert the insertion strategy was **never** invoked and
   state is `idle`.
3. **Next dictation clean:** after either cancel, run a full normal dictation
   and assert it completes with the expected inserted text.
4. **Idempotence:** `cancel()` twice in a row and in `idle` state — no
   exceptions, state stays `idle`.
