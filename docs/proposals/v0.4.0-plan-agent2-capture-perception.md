```python
    """Receives every audio block, whether or not a dictation is active.

    ``feed`` runs on the sounddevice callback thread and MUST return in
    microseconds — a bounded ``put_nowait`` with drop-on-full and nothing else.
```

```python

            logger.debug("Audio callback status: %s", status)

        audio_bytes = indata.tobytes()
        timestamp_ms = int(time.time() * 1000)

        # v0.4.0: ambient tap. Runs regardless of dictation state so Observer
        # hears the whole session. Read the reference once — set_ambient_sink
        # may swap it concurrently from the Qt thread.
        sink = self._ambient_sink
        if sink is not None:
            sink.feed(audio_bytes, timestamp_ms)
```

## Step 2 — OBS-11: `AmbientListener`

**File:** `src/agentvoca/observer/audio.py` (new)

Segments the ambient stream into utterances.

```python
class AmbientListener:
    """Turns the ambient mic tap into discrete utterances.

    Owns its OWN ``VAD`` instance — deliberately not shared with
    ``AudioCapture``'s. Silero is ~2 MB, and sharing one stateful streaming
    VAD across the dictation and ambient segmenters would need a lock on the
    audio hot path. Two instances is cheaper and far simpler.

    Thread: ``observer-ambient``, one daemon thread, started by
    ``start()`` and joined by ``stop()``.
    """

    def __init__(
        self,
        event_bus: EventBus,
        arbiter: "ASRArbiter",
        sample_rate: int = 16000,
        silence_timeout_ms: int = 900,
        min_utterance_ms: int = 400,
        max_utterance_ms: int = 30000,
        queue_depth: int = 64,
        on_speech_onset: "Callable[[], None] | None" = None,
    ) -> None: ...

    def feed(self, audio_bytes: bytes, timestamp_ms: int) -> None:
        """AmbientSink impl. Callback thread. put_nowait, drop-on-full."""

    def start(self) -> None: ...
    def stop(self, timeout: float = 2.0) -> None: ...
    def flush(self) -> None:
        """Force-emit any in-progress utterance. Test barrier + used at session stop."""
```

Segmentation state machine on the worker thread:

- `IDLE` → VAD says speech → transition to `SPEAKING`, start buffering, and
  fire `on_speech_onset()` **exactly once per utterance** (this is the
  speech-onset keyframe trigger, D9).
- `SPEAKING` → VAD says silence for ≥ `silence_timeout_ms` → emit the buffered
  utterance, return to `IDLE`.
- `SPEAKING` → buffer reaches `max_utterance_ms` → emit and immediately
  re-enter `SPEAKING` (someone talking continuously must not blow memory).
- Utterances shorter than `min_utterance_ms` are discarded — coughs, chair
  creaks, keyboard noise.
- Keep ~300 ms of pre-roll so the first word is not clipped. Use a
  `collections.deque(maxlen=…)` of blocks, not a growing list.

Emission hands the audio to the loop thread:
`asyncio.run_coroutine_threadsafe(self._arbiter.transcribe_ambient(...), loop)`.

Memory: `max_utterance_ms=30000` at 16 kHz float32 is ~1.9 MB per in-flight
utterance. The queue is bounded at `queue_depth` blocks (~4 KB each, ~256 KB).
Both well inside budget.

**Tests** — `tests/unit/test_ambient_listener.py` (stub the VAD with a
scripted speech/silence sequence; never load silero):
1. Speech → silence emits exactly one utterance with the expected byte length.
2. A 200 ms burst below `min_utterance_ms` emits nothing.
3. Continuous speech past `max_utterance_ms` emits multiple utterances and RSS
   stays bounded (`tracemalloc` peak < 3× one max utterance).
4. `on_speech_onset` fires once per utterance, not per block.
5. Pre-roll: the emitted buffer includes blocks from before the VAD flip.
6. Queue overflow drops blocks and `feed` never blocks (fill the queue, time
   1000 `feed` calls, assert total < 10 ms).
7. `stop()` joins within the timeout; `flush()` emits an in-progress utterance.

## Step 3 — OBS-12: `ASRArbiter`

**File:** `src/agentvoca/observer/arbiter.py` (new)
**Also:** `src/agentvoca/core/orchestrator.py` (routing only)

D10 says one ASR model instance serves both clients. D8 says dictation must
never suffer. This class is how both hold.

```python
class ASRArbiter:
    """Serializes access to the single ASRProvider, dictation first.

    Dictation calls ``transcribe_priority`` and is never queued behind ambient
    work. Ambient work runs on one worker coroutine that waits on
    ``_dictation_idle`` before every job, so it simply lags while a dictation
    is in flight.

    Lives entirely on the asyncio loop thread.
    """

    def __init__(self, provider: "ASRProvider", queue_depth: int = 16) -> None:
        self._provider = provider
        self._dictation_idle = asyncio.Event()
        self._dictation_idle.set()
        self._queue: asyncio.Queue = asyncio.Queue(maxsize=queue_depth)
        self._dropped = 0

    async def transcribe_priority(self, audio: bytes, context=None) -> str:
        """Dictation path. Blocks ambient for its duration."""
        self._dictation_idle.clear()
        try:
            return await self._provider.transcribe(audio, context)
        finally:
            self._dictation_idle.set()

    def submit_ambient(self, audio: bytes, ts_ms: int, context=None) -> bool:
        """Enqueue ambient work. Returns False if the queue was full.

        On overflow, drop the OLDEST job (a stale utterance is worth less than
        a fresh one) and increment the dropped counter. The caller records a
        ``gap`` event so the compiled output can say so honestly.
        """
```

The worker coroutine:

```python
    async def _worker(self) -> None:
        while True:
            job = await self._queue.get()
            if job is None:
                return
            await self._dictation_idle.wait()      # dictation always wins
            try:
                text = await self._provider.transcribe(job.audio, job.context)
                ...  # publish ObserverUtteranceEvent + store the row
            except Exception:
                logger.debug("Ambient transcription failed", exc_info=True)
            finally:
                self._queue.task_done()
```

`try/finally` around the `_dictation_idle` clear is essential — a raising
dictation transcription must not leave ambient starved forever.

**Orchestrator change (keep it minimal).** In
[orchestrator.py:769](../../src/agentvoca/core/orchestrator.py#L769) `_run_asr`,
route through the arbiter when one is attached:

```python
        if self._asr_arbiter is not None:
            transcript = await self._asr_arbiter.transcribe_priority(audio, context)
        else:
            transcript = await self._asr_provider.transcribe(audio, context)
```

Add `self._asr_arbiter = None` in `__init__` and an
`attach_asr_arbiter(arbiter)` setter. **Do not restructure `_run_pipeline`.**
When no arbiter is attached — every non-Observer user — behavior is
bit-identical to v0.3.6.

Also add the dictated-utterance hook. After a successful insertion in
`_run_pipeline`, publish `ObserverUtteranceEvent(text=…, source="dictated",
duration_ms=…)`. Publish unconditionally — the bus already no-ops when nobody
subscribes ([event_bus.py:63](../../src/agentvoca/core/event_bus.py#L63)), so
no `if observer_enabled` check is needed and the orchestrator stays ignorant of
Observer.

## Step 4 — OBS-13: the trigger gate

**File:** `src/agentvoca/observer/triggers.py` (new)

**This is the item that makes Observer viable rather than a firehose.** Write
the gate before the sources, and test it before wiring anything real.

```python
class TriggerGate:
    """Rate-limits keyframe requests. The ONLY path to a screen capture.

    Every trigger source calls ``request()``. Nothing else may enqueue a
    capture. Applies, in order:
      1. session not active or paused  → drop
      2. foreground app/title excluded → drop
      3. min_interval_ms since the last accepted capture → drop
      4. token bucket (max_keyframes_per_min) → drop
      5. capture queue full → drop, count, record a gap
    Thread-safe: called from the poll thread, the pynput mouse thread, and the
    ambient thread. One lock, held for microseconds.
    """

    def request(self, reason: TriggerReason) -> bool:
        """Returns True if the request was accepted and enqueued."""
```

Token bucket: capacity `max_keyframes_per_min` (default 4), refilled at
`capacity / 60` tokens per second, using `time.monotonic()` (never
`time.time()` — wall clock jumps). Allows a small burst on a genuine
context switch, then throttles hard.

The four sources:

**Window/title change** — `observer-triggers` daemon thread, 2 Hz, reusing
`ActiveAppDetector` from `context/active_app.py` unchanged. On a change:
record a `focus_change` event, then `request("window_change")`. Nothing else on
this thread — no grabbing, no OCR.

**Scroll settle** — `pynput.mouse.Listener(on_scroll=…)` on its own thread. The
handler only stamps `_last_scroll_monotonic`; the poll thread checks whether
`scroll_settle_ms` (default 600) has elapsed since the last scroll and fires
`request("scroll_settle")` **once** per scroll burst. Do **not** use a
`threading.Timer` per scroll event — a fast wheel produces hundreds and you
will have created the firehose you are trying to avoid.

**Click / selection** — same listener, `on_click`. On mouse-**up**:
- If the up position is > 5 px from the down position, treat it as a
  drag-select: fire `request("selection")` and ask the `SelectionReader`
  (OBS-18) for text.
- Otherwise fire `request("click")`.

**Speech onset** — `AmbientListener.on_speech_onset` → `request("speech_onset")`.

pynput handler rule: return in microseconds. Stamp a variable or call
`request()`, nothing more. A slow mouse handler makes the whole desktop feel
laggy and users will blame the OS, not you.

**Tests** — `tests/unit/test_trigger_gate.py` (inject a fake monotonic clock;
zero real time):
1. 1000 requests in one simulated second → at most 1 accepted (min_interval).
2. Over a simulated 10 minutes of continuous requests → ≤ 40 accepted
   (4/min token bucket).
3. Burst allowance: after 5 idle minutes, 4 rapid requests are accepted, the
   5th is not.
4. Excluded app → 0 accepted.
5. Paused → 0 accepted.
6. Full capture queue → returns False, increments the drop counter, and records
   a `gap`.
7. Thread safety: 8 threads × 500 requests; the accepted count still respects
   the bucket, and no exception.
8. Each disabled trigger flag drops that source only.

`tests/unit/test_trigger_sources.py`: scroll burst of 200 synthetic events →
exactly one `scroll_settle` after the quiet period; drag > 5 px yields
`selection`, click < 5 px yields `click`.

## Step 5 — OBS-14: screen grabber + dedup

**File:** `src/agentvoca/observer/screen.py` (new)

```python
class ScreenGrabber:
    """Grabs the active window rect, downscales, encodes JPEG, hashes.

    Thread: ``observer-capture``, one daemon thread draining a bounded queue.
    NOTE: this is NOT capture/screenshot.py — that drives the interactive OS
    snip UI and blocks for up to 30 s. This one is silent and programmatic.
    """

    def grab(self) -> Grab | None:
        """Grab the current active window. None if the rect is unavailable
        or degenerate (minimized, zero-area, off-screen)."""
```

Windows rect: `ctypes.windll.user32.GetForegroundWindow()` then
`GetWindowRect`. Prefer `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)`
where available — plain `GetWindowRect` includes the invisible drop-shadow
border on Win10/11 and you will capture a few px of whatever is behind. Fall
back to `GetWindowRect` if the DWM call fails.

Reject rects that are zero/negative area, smaller than 100×100, or fully
off-screen (minimized windows report `(-32000, -32000)`).

Grab with `PIL.ImageGrab.grab(bbox=rect, all_screens=True)`. `all_screens=True`
is required or a window on a secondary monitor grabs the wrong pixels.

Pipeline order — **this order matters for OCR quality**:
1. Grab at native resolution.
2. Compute dHash from the **native** image.
3. Dedup check against the last 8 hashes (Hamming ≤ `dedup_phash_distance`,
   default 6). Duplicate → return None, count it, done. **Never OCR a
   duplicate.** This is the single biggest CPU saving in the design.
4. Downscale to `max_width_px` (default 1280), preserving aspect, only if wider.
   `Image.LANCZOS`.
5. Encode JPEG at `jpeg_quality` (default 75).

dHash, in-repo, no new dep:

```python
def dhash(image: "Image.Image", hash_size: int = 8) -> int:
    """64-bit difference hash: grayscale, resize to (hash_size+1, hash_size),
    compare horizontally adjacent pixels, pack the bits."""
    small = image.convert("L").resize((hash_size + 1, hash_size), Image.LANCZOS)
    pixels = np.asarray(small, dtype=np.int16)
    bits = pixels[:, 1:] > pixels[:, :-1]
    return int(np.packbits(bits.flatten()).tobytes().hex(), 16)
```

Hamming distance via `bin(a ^ b).count("1")`.

Never hold a decoded PIL image beyond the function. Close it explicitly; a
4K RGB frame is ~24 MB and two of them live is a quarter of the RSS budget.

macOS/Linux (D4): return `None` with a single startup warning. The abstraction
exists; the implementation is v0.4.1.

**Tests** — `tests/unit/test_screen_dedup.py` (synthetic PIL images, never a
real screen):
1. Identical images → distance 0 → deduped.
2. A one-word text change → distance > threshold → not deduped.
3. dHash stable across a JPEG q75 round-trip (distance ≤ 2).
4. Downscale only when wider than `max_width_px`; aspect preserved; a
   1000 px-wide image is untouched.
5. Degenerate rects (zero-area, `-32000`, 50×50) return None.
6. Ring buffer holds exactly 8; the 9th hash evicts the 1st.
7. `tracemalloc` peak over 20 grabs of a synthetic 4K image stays under 2×
   one decoded frame — proves nothing is retained.

```python
class WindowsUIASelectionReader(SelectionReader):
    """Reads the current text selection via UI Automation TextPattern.

    NEVER touches the clipboard. NEVER injects keystrokes. This is the whole
    reason UIA was chosen over the Ctrl+C approach (D5).

    Thread: one long-lived ``observer-selection`` thread with COM initialized
    once via CoInitializeEx(COINIT_APARTMENTTHREADED). Per-call threads would
    pay COM init every time and risk apartment mismatches (RK5).
    """
```

Implementation:
1. `CoInitializeEx` once on the worker thread at start; `CoUninitialize` at stop.
2. `CUIAutomation` → `GetFocusedElement()`.
3. `GetCurrentPattern(UIA_TextPatternId)`; if the element has no text pattern,
   return None immediately — the caller falls back to OCR-rect.
4. `GetSelection()` → range array; `GetText(max_chars)` on the first range.
5. Truncate at `observer.selection.max_chars`; set `truncated=True` if cut.
6. Return `Selection(text=…, method="uia", …)`; return None for empty/whitespace.

**RK4 — the timeout is mandatory.** UIA calls can hang for seconds on Electron
apps and some PDF viewers. Run the call with a hard `timeout_ms` (default 250):
submit to a single-worker `ThreadPoolExecutor` owned by the reader and
`future.result(timeout=…)`. On `TimeoutError`, return None, log **once per app
name** (a per-call log on a hanging app will flood), and let the caller fall
back.
