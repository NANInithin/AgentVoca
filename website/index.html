How it works

Four steps from voice to cursor.

Choose your speech and cleanup models in setup. Change them later in Settings—no config editing needed.

01

Listen

Hold a key to talk, press once to start and stop, or let it stop when you go quiet.

push_to_talk · toggle · auto_stop
02

Transcribe

Use a free local model, or choose OpenAI, Groq, OpenRouter, or a custom speech endpoint.

faster-whisper · openai_compatible
03

Clean up

Keep the transcript as-is, use offline rules, or choose an AI model to polish it while preserving technical details.

rules · ollama · openai_compatible
04

Insert

Types into the focused app, with clipboard fallback, undo, and reinsert. Clipboard contents are restored if you haven’t copied something else.

keyboard · clipboard · undo

Use cases

For when typing slows you down.

Use it anywhere you can type: your editor, terminal, chat, docs and AI tools.

Prompting AI tools

Explain the whole problem out loud instead of typing a short version. Your prompts come out longer and clearer, with exact file names.

"refactor the auth middleware in src slash server dot ts to use the new session helper"
Refactor the auth middleware in src/server.ts to use the new session helper.

Commits, issues and reviews

Talk through what changed and get tidy prose with the technical details intact, typed straight into Git, GitHub or your tracker.

"fix um the retry loop in fetch user new paragraph closes issue four twelve"
Fix the retry loop in fetchUser.

Closes #412.

Turning screens into text

Snip a spreadsheet, chart or error dialog while you talk. You get markdown, which costs far fewer tokens than an image when you paste it into another AI tool.

Recording a work session

Local-first & model-agnostic

Your models. Your machine.

The default setup uses local speech recognition and offline cleanup. Cloud providers are your choice, and only the steps you configure for cloud use send data to that provider.

  • Offline by default. Uses faster-whisper and rule-based cleanup, with no key or account needed.
  • Clear consent in Observer mode. An on-screen badge and a red tray icon show the whole time it's recording.
  • Exclusions and control. Observer includes app exclusions and pause/resume. Retention has limits: stale open sessions and exports in custom folders may need manual deletion.
  • Cloud is opt-in. Cloud speech, cleanup, vision, or Observer providers send the relevant audio, text, or screen content to your chosen endpoint.
  • Keys stay in your OS credential store. Save a key once, delete it anytime, or choose when it expires. Without a credential store, it stays in memory for that session only.
# ~/.agentvoca/config.yaml
asr:
  provider: faster_whisper   # or openai_compatible
  model: base.en
cleanup:
  provider: rules            # or your chosen AI model
app:
  mode: toggle
streaming:
  enabled: false
observer:
  enabled: false
  compile: { provider: rules }
Install

A shorter path to your first dictation.

Install with uv, download the Windows app, or run from source. Choose the option that fits your machine.

Option A · Windows, macOS & LinuxInstall uv ↗

One command with uv

Install uv first, then install AgentVoca and start the app:

uv tool install "agentvoca @ git+https://github.com/NANInithin/AgentVoca"
agentvoca

uv downloads a supported Python (3.11–3.13) if needed and adds the agentvoca command to your PATH.

Upgrade with uv tool upgrade agentvoca. Remove with uv tool uninstall agentvoca.

Linux needs PortAudio for the microphone. On Debian or Ubuntu, run sudo apt install libportaudio2. Some desktop capture features are Windows-only.

Option B · WindowsView releases ↗

Download the app. No Python needed.

Download the latest AgentVoca-vX.X.X-windows-x64.zip from the Releases page, extract it, and double-click AgentVoca.exe.

The Windows download is still v0.4.1 and predates the latest setup changes. Use Option A for the latest repository version.

Option C · DevelopersREADME ↗

Run from source

git clone https://github.com/NANInithin/AgentVoca.git
cd AgentVoca
uv sync
uv run agentvoca

First launch

AgentVoca starts in the system tray and opens a short setup. Choose speech-to-text and cleanup; everything else uses sensible defaults.

01

Choose speech-to-text

Pick a free local Whisper model or a cloud provider and model. Local speech works offline after the first model download.

Local · OpenAI · Groq · OpenRouter
02

Choose cleanup

Use offline rules or an AI model to polish your text. For cloud models, choose a provider and model, then paste your API key.

Off · Rules · Local or cloud AI
03

Save and speak

Your config folder is created automatically. Press Ctrl+Space to start, then again to stop. More options live in tray Settings.

Ctrl+Space → speak → Ctrl+Space

No API key is needed by default: local faster-whisper and rules-based cleanup work offline. The first launch downloads your Whisper model (about 145 MB for base.en).

Cloud keys stay in Windows Credential Manager, macOS Keychain, or Linux Secret Service—not a plain file. Delete a key anytime, keep it until you delete it or close the app, or expire it after 1, 7, 30, or 90 days. Without a credential store, keys last only for the current session. Your own environment variables take priority over saved keys.

Change your choices anytime in Settings… from the tray menu. Read the full setup guide ↗
